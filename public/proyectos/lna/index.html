Amplificador de Bajo Ruido (LNA) 137 MHz

Este proyecto consiste en el diseño de un amplificador de bajo ruido (LNA) optimizado para la frecuencia de 137 MHz, ideal para captar las señales de los satélites meteorológicos NOAA.

Herramientas utilizadas:

  • KiCad (ngspice): Para las simulaciones iniciales de parámetros S.
  • Smith Chart: Para el cálculo de las redes de acoplamiento de entrada y salida.

El núcleo del diseño utiliza el transistor de radiofrecuencia BFR93A, buscando obtener la máxima ganancia posible con la menor figura de ruido.
