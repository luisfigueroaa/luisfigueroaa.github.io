Visualizador de Datos Electorales ONPE

Un script desarrollado en Python para automatizar la extracción de datos de las actas electorales de la ONPE y generar mapas visuales interactivos.

Características:

  • Uso de GeoPandas para el procesamiento de archivos GeoJSON de las regiones.
  • Renderizado de mapas limpios con D3.js siguiendo una estética web minimalista.
  • Clasificación automática por niveles de votación.
