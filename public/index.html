¿Porque este sitio web tiene un estilo particular?

No es que no sepa hacer sitios web más complejos y que no este familiarizado con tecnologías como Tailwind, Bootstrap, etc. Simplemente que soy alguien que sigue la filosofía Suckless. Es decir, trato de usar las herramientas actuales de la manera más pura y sencilla posible, es por esto que este sitio web esta hermosamente escrito en un formato semi-HTML2.

Mis herramientas de trabajo actualmente son VIM como editor de código (aunque por un caso práctico uso un pluge de VIM en VSCODE)

¿Qué es la filosofía Suckless?

La filosofía suckless es un enfoque de desarrollo de software que prioriza la simplicidad, la claridad y el control total del sistema. Se basa en la idea de construir herramientas pequeñas, modulares y fáciles de entender, evitando la complejidad innecesaria, las dependencias pesadas y las capas de abstracción que dificultan su mantenimiento. En este enfoque, el software se diseña para hacer una tarea específica de manera eficiente, manteniendo un código legible y modificable directamente por el usuario, promoviendo así la transparencia y la personalización a nivel de implementación.

Si estás interesado(a) en esta filosofía suckless puedes escribirme por mail o visitar el sitio oficial de suckless.
